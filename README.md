# 码林外史

《码林外史》是一部长篇纪实小说，由几名码农协作撰写，尝试展现中国基础软件行业从业人员二十年来的艰苦探索，并揭露行业中存在的一些弊端。

专有名词对照表：

- 中为：华为
- 华静止：中移动
- 河马操作系统：鸿蒙操作系统
- 围场许可证：木兰许可证
- 普顿大学：普林斯顿大学
- 成万公司：诚迈公司
- 零度：深度
- 淘贝集团：阿里集团
- 南北火凤系统：天津麒麟、中标麒麟
- 一统：统信
- 方格：方舟；（方块处理器，方框操作系统）
- 红桃一号：龙芯一号
- 者也网：知乎网

主要人物及线索（按出场顺序）：

- 七爷：一个中年过气码农，开了一家良机酒家，成为基础软件行业和投资圈交流的重要场所。小说里的故事主要发生在良机酒家。小说中出现的各种人物，主要通过七爷的回忆、心理活动等进行背景交代。
- 小翠：良机酒家服务员。聪明伶俐，会来事儿。因长期接触良机酒家的来客，积攒了丰富的人脉，后被圈内投机大佬看中，先做运营长，后当CEO，但最后成了背锅人。
- 亮爷：七爷的大学同学，某民营基金投资经理。
- 王一鸣：天赐操作系统创始人，富二代，留美研究生。国产操作系统最后的成功者。
- 海川：一名来自青岛的中年码农，亲历国内芯片第一股成长历程，可惜成了内部斗争的牺牲品。
- 泰爷：北京人，喜欢卖点关子，爱打探圈内秘密。
- 浩哥：一个看似愤世嫉俗的 80 后码农，啥都看不惯的样子，但有点懒，总想着赚快钱，会投机。在安可大潮中，通过传授开源软件美颜术大赚了一把。
- 小青：某国企北京基础软件分公司总经理，小翠的同乡及高中同学。

撰写要求：

1. 凡是有名有姓，多次出场的人物，要通过外貌、声音等的细节描写来刻画，使人物特征更为饱满。
1. 每个人物要尽量保持一致的语言特征，新引入的人物，可以通过七爷的回忆交代相关的背景。
1. 每一回的字数应在 3000 字到 5000 字。
1. 每周通过《操作系统百家谈》公众号发表已经就绪的章回，每月四次，每次两回。在公众号上首发一周后，发表到知乎等网站上。

发布要求：

1. 字体 17px，段前间距 15，段后间距 20。
1. 保留 Markdown 生成文档的引用效果以及分节水平线。
1. 所有正文文后统一增加如下内容（水平居中）：

```
本文人物情节纯粹虚构
如有雷同，巧合使然
```

1. 《码林外史》专辑链接
